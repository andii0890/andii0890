I'm a full-stack software developer with over seven years of experience building and maintaining web applications across frontend and backend. I specialize in JavaScript-based technologies, including React, Next.js, and Node.js, with hands-on experience designing APIs, managing relational and NoSQL databases, and deploying applications on cloud platforms such as AWS and Vercel. In 2025 I co-founded **GG Labs**, a software development studio where I now build and ship our own product portfolio for the gaming and 3D-printing markets. I actively integrate AI-assisted development tools into my workflow for coding, debugging, code review, research, and documentation.
